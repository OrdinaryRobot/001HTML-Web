Hugo Theme Stack 的首页由主题模板（`layouts/home.html`）直接渲染文章列表，
不会输出本文件的正文内容。下面的站内导航仅作备忘保留。

## 站内导航

| 页面 | 地址 | 说明 |
|---|---|---|
| 文章 | `/posts/` | 查看所有博文 |
| 搜索 | `/search/` | 全站内容检索 |
| 归档 | `/archives/` | 按时间浏览全部文章 |
| 关于我 | `/about/` | 个人介绍 |
| 旧站练习页 | `/legacy/index.html` | 课程练习阶段的静态页面存档 |
| 归档说明 | `/legacy-guide/` | 旧站文件的整理说明 |

侧边栏里也可以直接进入上述页面。

## 留言

每篇文章底部都可以评论，欢迎交流。
