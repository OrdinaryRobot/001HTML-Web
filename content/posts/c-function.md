## 1. 函数概念

函数实际上是一个小程序，里面包装了预先写好的代码，用于减少重复代码的书写，比如 `main`、`scanf`、`printf`。

## 2. 函数的形式

**数据类型 + 函数名 +（参数）**，`(void)` 表示没有参数。

```c
int name(int x, int y)   // 函数头
{
    return x + y;        // 函数体
}
```

## 3. 库函数

- 预先写好、包装好的函数，被集中放在库文件中，配有说明书「头文件」。
- 一般由编译器厂商放在自家编译器中。

## 4. 自定义函数

一串自己写的代码：

```c
#include <stdio.h>

// 定义函数
int average(int x, int y)
{
    int z = (x + y) / 2;

    return z;
}

int main()
{
    int a, b;

    scanf("%d %d", &a, &b);

    int r = average(a, b);

    printf("%d", r);

    return 0;
}
```

## 参数：形参和实参

- **形参**，即定义函数时的参数（`int x, y`），它们在未被调用、没有存储实参时，不会申请占用内存，并不是真实存在的。
- **实参**，即传递给函数的参数（如 `a`、`b`），它们是实际存在的。
