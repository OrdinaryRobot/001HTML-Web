## ***经典：判断素数***

```c

#include<stdio.h>

int main(){

    int n=0;
    int t=1;

    scanf("%d",&n);
    if(n<=1){

        return 0;
    }else{

        for(int i=2;i<n;i++){

            if(n%i==0 && n!=2){

                t=0;
                break;
            }
        }
    }

    if(t==1){
        printf("Yes");

    }else{
        printf("No");
    }

    return 0;
}
```
- **定义变量**（比如 `int t = 1;`）：这相当于给变量办“出生证明”。如果在循环里定义，那出了循环它就“死”了（作用域结束），外面确实访问不到。
- **修改变量**（比如 `t = 0;`）：这相当于给变量“换个衣服”。==🟡只要这个变量在之前已经“出生”了==（在循环外面定义过了），==🟠你在哪里修改它都可以==。

## **判断回文数**

回文数：即一个数字，形如111，121，1001，反转之后依然等于这个数的数叫做回文数

判断回文数的程序：
```c
int n;
scanf("%d",&n);
```
读取数字
 ```c
 int original=n;//先记下这个数字
 int reserve;//记录反转的数字
 ```
初始化
 ```c
 while(n>0){
      reserve=reserve*10+n%10;
      n/=10;
 }
 ```
反转数字
```c
if(reserve==original){
   printf("0K");
}else{
   printf("N0");
}
```
