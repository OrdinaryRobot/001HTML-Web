{{- /* ========================================================================== 评论系统 —— 云服务 iframe 嵌入版（Stack 自定义 provider） -------------------------------------------------------------------------- 为什么不用现成 provider（Disqus / Giscus / Waline…）： 我们自己那套评论系统跑在 WorkBuddy 云服务上，功能更贴合需求 —— 免登录、敏感词过滤、昵称锁定、站长口令删除。 为什么必须用 iframe 而不是直接 fetch： 云服务的 data-plane API 会校验请求 Origin 白名单，只放行应用自己的域名 （blog-comments.app.workbuddy.host）。博客在 GitHub Pages 上，Origin 不在白名单，浏览器直连会被 403 拒绝。把控件放进 iframe 后，请求就是从 白名单域名发出的，即可正常读写。 通信约定： · 父页面 → iframe：下发主题（light / dark） · iframe → 父页面：上报内容高度，实现无内部滚动条的自适应 ========================================================================== */ -}} {{- $frameOrigin := "https://blog-comments.app.workbuddy.host" -}} {{- $frameSrc := printf "%s/?page=%s" $frameOrigin (.RelPermalink | urlquery) -}}
