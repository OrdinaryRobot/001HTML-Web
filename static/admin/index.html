连接 GitHub

填写一次即可，之后存在这台设备的浏览器里。
怎么拿令牌（大约 1 分钟）：
  1. 打开 github.com/settings/personal-access-tokens/new
  2. Token name 随便填，比如 blog-admin
  3. Expiration 建议选 90 天（到期换一个就行）
  4. Repository access 选 Only select repositories，勾上 001HTML-Web
  5. Permissions → Repository permissions → 找到 Contents，设为 Read and write
  6. 点最下面 Generate token，把 github_pat_... 整串复制过来
令牌只保存在你这台设备的浏览器里，不会上传到任何地方。如果你在别人的电脑上用过，记得点「清除」。
